## 실기기 체크리스트

초기 화면과 `Tab` 전환 표시는 관찰했지만, 아래 실기기 동작 대부분은 수행하지 못해 `UNVERIFIED`다.

- [ ] 기본 JOG A에서 전체 트랙패드가 Deck A만 스크래치
- [ ] `Tab` 후 다음 터치가 Deck B만 제어하고, 진행 중 터치는 시작 덱에 유지
- [ ] 일반 스크래치와 `Shift` 시작 피치 벤드의 방향·감도·50ms 정지·종료 복귀
- [ ] 피치 벤드 중 클릭 노이즈가 없고 정지 덱 재생 위치가 유지
- [ ] 수평·대각선 이동이 볼륨, 필터나 크로스페이더를 변경하지 않음
- [ ] `P` 잠금·해제와 `Esc`, 파일 선택, 포커스 상실, 창 닫기 후 커서 복구
- [x] 초기 활성 덱 외곽선과 `JOG A/B · SCRATCH`의 `Tab` 전환 표시
- [ ] 실제 조그 중 `BEND`, `NEXT`와 `CURSOR LOCKED` 표시
- [ ] 실제 음악의 자동 BPM·첫 박자 정확도와 분석 실패 표시
- [ ] `B` 탭 보정, `Shift+B` 자동 복원과 새 트랙 로드 후 초기화
- [ ] `S` 원샷 SYNC 뒤 템포만 맞고 위상은 수동 조그로 조절 가능
- [ ] 실제 음악 두 곡 로드 → 큐 → 재생 → SYNC/템포 → 볼륨·필터 → 크로스페이드
- [ ] 헤드폰 왼쪽에서 Master만, 오른쪽에서 `V`로 선택한 Cue만 청취
- [ ] 프리큐 토글 중 왼쪽 Master 음량 불변과 두 덱 동시 프리큐 헤드룸
- [ ] 헤드폰 또는 출력 장치 연결·해제 후 안전한 복구와 프리큐 무유출
- [ ] 30분 연속 믹싱 중 클릭, 멈춤, 잘못된 키 고정과 상태 누적 없음

실기기 검증 시 사용한 맥북·트랙패드, 오디오 장치, macOS 버전, 트랙 형식·샘플레이트와 관찰 결과를 함께 기록한다. 빌드 성공이나 합성 신호 PASS만으로 이 체크박스를 완료 처리하지 않는다.
